# danielmorales.me

Personal site and blog. Minimal, blog-first design.

## Stack

- [Astro 5](https://astro.build) — static + SSR
- [Tailwind CSS v4](https://tailwindcss.com) — styling
- [shadcn/ui](https://ui.shadcn.com) — component primitives
- [MDX](https://mdxjs.com) — blog posts
- [Cloudflare Workers](https://developers.cloudflare.com/workers/) — hosting
- [Geist Mono](https://vercel.com/font) — typeface

## Development

```bash
bun install
bun run dev
```

## Build & Deploy

```bash
bun run build
bun run deploy:staging
bun run deploy:prod
```
